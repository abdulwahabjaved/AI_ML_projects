This repository contains 3 Machine Learning tasks completed using Python, Pandas, Scikit-learn, and data visualization libraries.

---

## 📋 Tasks Overview

| Task | Title | Model Used | Dataset |
|------|-------|-----------|---------|
| Task 1 | Iris Dataset Visualization | EDA Only | Iris (Seaborn) |
| Task 2 | Stock Price Prediction | Linear Regression, Random Forest | Yahoo Finance |
| Task 3 | Heart Disease Prediction | Logistic Regression, Decision Tree | Heart Disease UCI |

---

## 🛠️ Libraries Used
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- YFinance

---

## ▶️ How to Run
1. Install libraries:
```bash
   pip install pandas numpy matplotlib seaborn scikit-learn yfinance jupyter
```
2. Open any notebook:
```bash
   jupyter notebook
```
3. Run cells one by one using `Shift + Enter`
