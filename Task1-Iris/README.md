# Task 1: Exploring and Visualizing the Iris Dataset

## Objective
Load, inspect, and visualize the Iris dataset to understand data trends and distributions.

## Dataset
Iris Dataset — loaded directly via Seaborn library (no download needed)

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## What Was Done
- Loaded dataset using Pandas and Seaborn
- Printed shape, column names using `.head()`
- Used `.info()` and `.describe()` for summary statistics
- Created Scatter Plots (Sepal and Petal features)
- Used Histograms to show value distributions
- Used Box Plots to identify outliers
- Created Pairplot for all features
- Created Correlation Heatmap

## Results
- Setosa species is clearly separable from others
- Petal Length and Petal Width are highly correlated (0.96)
- Sepal Width has some outliers in Setosa species
